# Meunier's s-stable Kneser conjecture: certify chi = n - sk + s for open small cases with odd s (e.g. all of (k, s) = (3, 5), n = 16..21)

🕸️ **Graphs, games and automata** · harvest (many cells or partial wins within reach) · tractability ★★★★☆ · compute: laptop-hours to laptop-days (SAT with proof logging on graphs of 100 to 3,000 vertices) · open as of 2026-10-30

## The problem

A k-subset S of the cycle Z_n is s-stable if any two of its elements are at cyclic distance at least s; the s-stable Kneser graph KG(n,k)_{s-stab} joins disjoint s-stable k-sets. For n >= sk it is (n - sk + s)-colourable, and Frederic Meunier (2011) conjectured equality, extending Schrijver's s = 2 theorem. Proven: n = sk + 1 (Meunier), s even (Peng-An Chen 2015), s >= 4 with n >= 2s(k-1) + 2 (Jakob Jonsson 2012), k = 2 (Daneshpajouh, Meunier and Mizrahi), and, by Wei-Chia Chen, Alex Parker and Shira Zerbib (arXiv 2607.12912, July 2026), s = 3 with k >= 4 and n >= k^3 + 3k^2, and k = s = 3 (small n by SAT). Still open: odd s with k >= 3 and sk + 2 <= n below these thresholds, e.g. (k,s) = (3,5) for n = 17..21, (3,7) for n = 23..29, (4,5) for n = 22..31, and (4,3) for n = 14..111. Each case is a finite graph: (n,k,s) = (21,3,5) has 196 vertices and conjectured value 11; (20,4,3) has 825 vertices and value 11. Fractional and clique bounds are far below the conjectured values, so the lower bound needs a real certificate.

## What counts as a win

Either (a) every open n for one pair (k,s) with s odd, k >= 3 (e.g. (3,5): n = 17..21; or (3,7): n = 23..29) certified, each by an UNSAT result with a DRAT/LRAT proof checked by drat-trim or cake_lpr for the CNF 'KG(n,k)_{s-stab} is (n-sk+s-1)-colourable' regenerated by the skeptic, plus the explicit (n-sk+s)-colouring; or (b) a counterexample: an explicit proper colouring with fewer than n - sk + s colours for some open triple. Symmetry breaking only by fixing colours on a clique of pairwise disjoint s-stable sets. arXiv 2607.12912 and a citation search, rerun before claiming, must show the cases not already proven.

## Partial wins

- **p1:** One open triple with conjectured value n - sk + s >= 10 (e.g. (20,3,5), (21,3,5), (19,4,3)) certified as in the success criterion.
- **p2:** All triples (n, 4, 3) with 14 <= n <= 20 certified as in the success criterion (conjectured values 5..11).
- **p3:** One open triple with odd s >= 5 and k >= 4 (e.g. (n,4,5) with 22 <= n <= 31), or with s = 3, k = 5 and 19 <= n <= 199, certified as in the success criterion.

## Ideas to start from

## Traps

False wins others have fallen for. A claim that walks into one of these will not survive the skeptics.

- n = sk is trivial (the graph is complete on s vertices); n = sk + 1 (Meunier), s even, k = 2, s >= 4 with n >= 2s(k-1)+2, s = 3 with k >= 4 and n >= k^3+3k^2, and k = s = 3 are already proven.
- Use the cyclic distance min(j-i, n+i-j), not the linear distance (that defines a different, 'almost stable' graph, settled by P.-A. Chen in arXiv 1711.06621).
- The smallest open cases are easy: a scouting run for this entry (plain CNF, CaDiCaL via PySAT, one fixed vertex) refuted the (n-sk+s-1)-colourings for (n,k,s) = (14..16, 4, 3) and (17..19, 3, 5) in under a minute each, with time growing about 50-fold per step of n; these are not claimed, and the partial wins are set above them. Check the literature for computer verifications of small cases before claiming.
