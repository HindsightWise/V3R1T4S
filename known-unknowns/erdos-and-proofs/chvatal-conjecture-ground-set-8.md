# MOONSHOT - Chvátal's conjecture (Erdős #701): a downset whose largest intersecting subfamily beats every star, or a certified verification for ground sets of 8 elements

## The problem

Chvátal's conjecture (1974; Erdős Problem #701, open on erdosproblems.com on 2026-10-30) says: if F is a finite family closed under taking subsets (a downset), then some maximum-size intersecting subfamily of F is a star {A in F : x in A}. Several special cases are proved: Chvátal's own (families compressed with respect to an order), Sterboul (1974), Kleitman-Magnanti (1972) and Frankl-Kupavskii (2023) for intersecting subfamilies with covering number 2, and Borg (2011) for weighted versions. The computational frontier is the ground-set size. Eifler, Gleixner and Pulaj ('Chvátal's Conjecture Holds for Ground Sets of Seven Elements', Zuse Institute Berlin report, 2018) verified every downset on at most 7 elements with exact-arithmetic integer programming. The erdosproblems forum thread (comments up to 22 May 2026) cites no larger verification, and the problem page lists none. There are D(8) ≈ 5.6e22 downsets on 8 points (the Dedekind number), so any ground-set-8 approach needs symmetry and IP/SAT reasoning rather than enumeration. The formal-conjectures repository has a Lean statement (ErdosProblems/701.lean).

## What counts as a win

Success means a counterexample: an explicit downset F, given by its maximal members on a finite ground set, and an explicit intersecting subfamily G of F with |G| strictly greater than max over x of |{A in F : x in A}| (direction: exceed every star). The verifier generates F as the down-closure of the maximal members and checks that G ⊆ F with distinct members. It checks that members of G pairwise intersect, so the empty set cannot be in G, computes every star size exactly, and compares. By the 2018 verification, any counterexample has at least 8 ground elements.

## Partial wins

- **p1:** A certified verification that the conjecture holds for all downsets on 8 elements. Every computational step must carry a certificate an independent checker accepts (VIPR for exact IP, or LRAT for SAT), and the code must regenerate every subproblem. It counts only if the skeptic finds no earlier published verification for 8 elements.
- **p2:** A Lean 4 proof, with no sorry and only standard axioms, of the covering-number-2 case (Kleitman-Magnanti 1972, Frankl-Kupavskii 2023), in the setting of the formal-conjectures definitions for Erdős #701. The statement: for every finite nonempty type X, every lower set F of Set X and every intersecting F' ⊆ F such that some set of at most 2 elements meets every member of F', there is x with #F' <= #{A ∈ F : x ∈ A}. It counts only if no formal proof of this case is already public.

## How a win is checked

For a counterexample: compute the down-closure by bitmask enumeration over subsets of each maximal member, verify G's membership and pairwise intersection, and compute all star sizes with two independent scripts. For p1: replay the IP/SAT certificates with VIPR or cake_lpr and audit the symmetry reduction. For p2: lake build against the pinned toolchain and #print axioms.

## Ideas to start from

Starting points, not instructions. The best wins came from angles nobody listed.

- Follow Eifler-Gleixner-Pulaj: for a fixed downset, the largest intersecting subfamily is a maximum-weight independent set problem; reformulate 'all downsets on 8 points' as one IP over downset indicator variables with symmetry breaking, solved by an exact solver that emits VIPR certificates.
- Search for counterexamples among downsets generated by few maximal sets with large symmetry groups (designs, Kneser-like layers), where both the star sizes and the intersecting optimum can be computed exactly and fast.
- Known proved cases (compressed families, covering number 2) rule out large regions; encode them as cuts to shrink the ground-set-8 search.

## Traps

False wins others have fallen for. A claim that walks into one of these will not survive the skeptics.

- The conjecture compares with the largest star inside F, not the star in the full power set.
- The empty set lies in every non-empty downset but in no intersecting subfamily of size >= 2; handle it consistently in both counts.
- Infinite ground sets are discussed on the forum but are not the target; the criterion is finite.
