# Zarankiewicz numbers for K_{3,3} and K_{4,4}: the exact values z(17;3,3) and z(14;4,4) (next terms of OEIS A001198 and A006616)

📊 **Record tables** · harvest (many cells or partial wins within reach) · tractability ★★☆☆☆ · compute: laptop-days (SAT with row/column degree-partition splitting as in Tan 2022, who ran one processor per instance and reports a practical limit near z = 100; z(17;3,3) lies above that, so cube-and-conquer parallelism will help) · open as of 2026-10-30

## The problem

z(m,n;a) is the largest number of ones in an m x n 0-1 matrix with no a x a all-ones submatrix (OEIS lists k_a(n) = z(n,n;a) + 1). Jeremy Tan ('An attack on Zarankiewicz's problem through SAT solving', arXiv:2203.02283 v2, Apr 2022; code and data at github.com/Parcly-Taxel/Kyoto) corrected Guy's 1969 tables and extended them with Kissat. His Tables 3 and 4 give z3(m,n) for m <= 16 and z4(m,n) for m <= 13; bold entries are exact and the rest are Roman's bound. OEIS A001198 and A350304 (Howroyd, Alekseyev, Tan) know z(n;3,3) for n <= 16, ending with z(16;3,3) = 128 (Tan, 2022). OEIS A006616 and A347474 (Howroyd, Alekseyev) know z(n;4,4) for n <= 13 (z(13;4,4) = 117). Later work moved rectangular cells but no square one. Davies, Gill and Horsley (arXiv:2411.18842, Discrete Math. 2026) improved many Roman upper bounds. Bhan, Nobili and Langer (arXiv:2605.01120), Afrasyab (arXiv:2608.08154), Hou (arXiv:2608.08549) and Saurabh (arXiv:2608.26603) settled or improved (3,3) cells with n = 17..23, and so did two unreviewed GitHub repositories (dfield/finite-zarankiewicz-closures; joaoamaro70/zarankiewicz, e.g. z(13,20;3,3) = 125) and an SSRN preprint by Padhi (abstract 6960039). 132 <= z(16,17;3,3) <= 133 is still open. Tan's matrix for z3(16) is the only known maximal one, but completeness is unproven. The case a = 2 is excluded (partial win p2 of turan-cycle-free-afzaly-mckay).

## What counts as a win

Success means the EXACT value of z(17;3,3) or z(14;4,4), shown by (i) an explicit n x n 0-1 matrix with z ones and no a x a all-ones submatrix, checked exhaustively, and (ii) a proof that z+1 ones force such a submatrix. The computational part of (ii) must be certified (LRAT/DRAT checked by cake_lpr or drat-trim, VeriPB, or an exact ILP certificate), and its case split (row/column degree partitions) must be written out and re-generated by the verifier. The value must not already appear in OEIS A001198, A350304, A006616 or A347474, or in a paper, preprint or public repository found at claim time (check all papers citing arXiv:2203.02283, including arXiv:2411.18842, 2605.01120, 2608.08154, 2608.08549 and 2608.26603, plus github.com/dfield/finite-zarankiewicz-closures, github.com/joaoamaro70/zarankiewicz and SSRN abstract 6960039).

## Partial wins

- **p1:** An exact value, to the same certificate standard, for a cell z3(m,n) or z4(m,n) of Tan's Tables 3-4 (arXiv:2203.02283 v2) that the paper does not mark exact (not bold) and that no later source has settled. Check arXiv:2411.18842, 2605.01120, 2608.08154, 2608.08549, 2608.26603, github.com/dfield/finite-zarankiewicz-closures, github.com/joaoamaro70/zarankiewicz, SSRN abstract 6960039 and any later paper or repository citing Tan; for example, z(13,18;3,3) = 116 and z(13,20;3,3) = 125 are already settled.
- **p2:** A certified proof that the matrix shown by Tan is the unique maximal matrix for z(16;3,3) up to row/column permutation and transposition, or an explicit second non-isomorphic 16 x 16 matrix with 128 ones and no 3 x 3 all-ones submatrix (non-isomorphism checked with nauty on the bipartite graphs).

## How a win is checked

Check the matrix size and count ones; enumerate all choices of a rows and test whether their common ones reach a columns (C(17,3) = 680 triples for a = 3, C(14,4) = 1001 quadruples for a = 4). For the upper bound, regenerate the CNF instances from the written case split with an independent encoder, run the supplied proofs through drat-trim or cake_lpr, and check the partitions cover all degree sequences. Re-fetch OEIS A001198, A006616 and search for papers citing arXiv:2203.02283.

## Traps
