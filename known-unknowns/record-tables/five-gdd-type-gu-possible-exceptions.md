# 5-GDDs of type g^u: settle a possible exception in Forbes' 2023 theorem (smallest 2^15, then 10^7)

## The problem

A 5-GDD of type g^u is a set of gu points split into u groups of size g, with 5-point blocks such that every pair of points from different groups lies in exactly one block and no pair within a group lies in a block. The necessary conditions are u >= 5, g(u-1) = 0 (mod 4) and g^2 u(u-1) = 0 (mod 20). Wei and Ge (2014) proved them sufficient with many possible exceptions. A. D. Forbes (Australas. J. Combin. 87 (2023) 1-11; arXiv:2202.13911, Theorem 1.2) reduced the list. The conditions are sufficient except for the non-existent types 2^5, 2^11, 3^5 and 6^5, and except possibly for: 3^65; 2^15, 2^75, 2^95, 2^115; 6^35, 6^95; g in {14,18,22,26,38,58} with u in {11,15}; g in {74,82,86,94} with u = 15; 10^5, 10^7, 10^27, 10^39, 10^47; 50^27. The g = 0 (mod 10) part of the list is repeated unchanged in Forbes and Rutherford (La Matematica 2024; arXiv:2111.13599v3, Lemma 3.1(vii)). Type 10^5 is a TD(5,10), equivalent to three MOLS of order 10, which is the bank target three-mols-order-10; it is excluded here. By point count the smallest open cases are 2^15 (30 points, 42 blocks), 10^7 (70 points, 210 blocks), 2^75 (150 points) and 14^11 (154 points).

## What counts as a win

Success means an explicit 5-GDD of one of the listed types other than 10^5: a point set of size gu, a partition into u groups of size g, and a list of 5-subsets such that every pair from distinct groups lies in exactly one block and no block contains two points of one group. Two independent programs must verify it. The type must still be a possible exception at claim time. Check the latest Forbes papers via his arXiv author page and ORCID record, and run a fresh literature search for that type.

## Partial wins

- **p1:** A machine-checked non-existence proof for a listed type (for example 2^15), delivered as a DRAT/LRAT-verified UNSAT certificate from an encoding a skeptic audits, or as an exhaustive search independently reproduced.
- **p2:** A certified exhaustive search showing that no 5-GDD of type 2^15 or 10^7 admits a stated automorphism group of order at least 3 (for example the cyclic group generated by x -> x+g on a cyclic point labelling), for a group not already excluded in the literature, with a DRAT/LRAT certificate or a reproduced enumeration.

## How a win is checked

Check the point count, the group partition (all sizes g) and that every block has 5 distinct points meeting each group at most once. Count pair coverage over all cross-group pairs (exactly 1) and confirm that the block count is (C(gu,2) - u C(g,2))/10. When base blocks and a development rule are given, expand them with the verifier's own code. This reproduces Forbes' published 6^15 example (378 blocks), which was checked this way on 2026-10-30.
